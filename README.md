# Fine Art Shop · Prototyp

Statischer Prototyp eines Fine Art Print Shops mit Bewertungsmodus für Freunde.

* `index.html` Kollektion, Produktansicht, Bewertungsmodus (Schulnote 1 bis 5 mit Smiley plus Kommentar)
* `auswertung.html` Übersicht aller Bewertungen pro Motiv
* `config.js` Markenname, Preise, Supabase Zugang
* `supabase.sql` Tabelle und Zugriffsregeln für die Bewertungen
* `produkte.js` und `bilder/` werden von `shop_bauen.py` erzeugt

Ohne Supabase Eintrag in `config.js` werden Bewertungen nur im jeweiligen Browser gespeichert.

Die Motive wurden mit Unterstützung von KI (FLUX 3 Klein) erstellt.
